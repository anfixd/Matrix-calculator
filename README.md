# Matrix Calculator

Консольный калькулятор матриц на C++17. Позволяет создавать матрицы, заполнять их и выполнять над ними операции: сложение, вычитание, умножение, возведение в степень, вычисление определителя, ранга и транспонирование.

## Сборка

Нужны компилятор `g++` с поддержкой C++17 и (по желанию) `make`.

```
make
./matrix_calc
```

На Windows запускайте `matrix_calc.exe`.

Без `make`:

```
g++ -std=c++17 -O2 main.cpp commands.cpp matrix.cpp matrix_ops.cpp messages.cpp -o matrix_calc
```

Очистка результатов сборки: `make clean`.

## Использование

После запуска программа ждёт команды. Команда `help` выводит их список. Матрицы нумеруются с нуля в порядке создания.

### Работа с матрицами

| Команда | Описание |
|---|---|
| `help` | показать список команд |
| `create N M` | создать матрицу размера N×M |
| `resize ID N M` | изменить размер матрицы ID на N×M |
| `fill ID {значения}` | заполнить матрицу ID по строкам |
| `setval ID X Y VAL` | записать значение VAL в ячейку (X, Y) матрицы ID |
| `print ID` | вывести матрицу ID |
| `delete ID` | удалить матрицу ID |
| `setac VAL` | задать число знаков после запятой при выводе |

### Операции

| Команда | Описание |
|---|---|
| `sum ID1 ID2` | сумма матриц |
| `sub ID1 ID2` | разность матриц |
| `mult ID1 ID2` | произведение матриц |
| `pow ID N` | возведение квадратной матрицы в степень N |
| `push` | добавить текущий результат в конец списка матриц |
| `det ID` | определитель квадратной матрицы |
| `rang ID` | ранг матрицы |
| `tran ID` | транспонированная матрица |
| `exit` | выход |

Результат операций `sum`, `sub`, `mult`, `pow`, `tran` сохраняется как текущий. Чтобы использовать его в следующих операциях, добавьте его в список командой `push`.

### Пример

```
create 2 2
fill 0 1 2 3 4
setac 1
mult 0 0
push
det 0
```

Результат умножения:

```
7.0 10.0
15.0 22.0
```

Определитель: `-2.0`.

## Структура проекта

| Файл | Назначение |
|---|---|
| `types.h` | общий тип `ll` (`long long`) |
| `messages.h/.cpp` | сообщения об ошибках и успехе, настройка точности вывода |
| `matrix.h/.cpp` | класс `Matrix` |
| `matrix_ops.h/.cpp` | операции над матрицами |
| `commands.h/.cpp` | разбор и выполнение команд |
| `main.cpp` | точка входа |
| `Makefile` | сборка |

Файлы `types`, `messages`, `matrix` и `matrix_ops` образуют библиотеку `libmatrix.a`, которую можно подключать к другим проектам. Файлы `commands` и `main` составляют консольное приложение.

## Известные ограничения

- Определитель считается разложением по первой строке, поэтому для больших матриц (порядка 10 и выше) работает медленно.
- При сложении и вычитании матриц разных размеров недостающие элементы считаются нулями.
